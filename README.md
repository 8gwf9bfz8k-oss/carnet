# Carnet

Carnet d'entraînement minimaliste pour iPhone : séances de muscu série par série, course et sprints, programme de la semaine, courbes de progrès.

Installation : ouvrir le site dans Safari, puis Partager › Sur l'écran d'accueil.
Les données restent sur l'appareil (export / import dans l'onglet Progrès).
